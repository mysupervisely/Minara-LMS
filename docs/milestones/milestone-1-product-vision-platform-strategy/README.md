# Milestone 1 — Product Vision & Platform Strategy

**Status:** Draft
**Phase:** Phase 1 — Product Architecture
**Date:** 2026-08-06
**Scope:** Documentation only. No code, frameworks, vendors, or database
schemas are defined in this milestone.

## Purpose

This milestone establishes the foundational product thinking for
Minara-LMS: what it is, why it exists, who it serves, and how its scope is
bounded relative to the rest of the Minara ecosystem. It is the reference
point that all later architecture (data model, service design, portal
specifications, integration design) will be evaluated against for
consistency.

## Relationship to Later Milestones

This milestone deliberately stops short of technical architecture. It does
not specify:

- Data models or database schemas
- Service boundaries or system architecture
- Technology stack, frameworks, or vendors
- API contracts
- UI/UX design

Those are expected to be the subject of later milestones (e.g., Milestone
2+: Information Architecture, Data Model, Technical Architecture, Portal
Specifications), each of which should be traceable back to the principles
and scope established here.
